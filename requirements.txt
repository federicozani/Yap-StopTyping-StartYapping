# Yap dependencies. Install with:
#   pip3 install -r requirements.txt
rumps                    # the menu bar app framework
pynput                   # global hotkey (hold-to-talk) + simulating Cmd+V
sounddevice              # recording from the microphone
numpy                    # holding the audio samples in memory
requests                 # calling the Gemini API
pyobjc-framework-WebKit  # the embedded web-view UI (Settings / onboarding / quick panel)
pyobjc-framework-AVFoundation  # Microphone permission detection/prompt during onboarding
# (Input Monitoring uses Quartz and Accessibility uses ApplicationServices —
#  both already ship as dependencies of pyobjc-framework-WebKit.)
